# Security Policy

## Supported versions

This project is maintained on the default branch (`main`). Security fixes are expected to be merged there before being backported to any other supported branch.

## Reporting a vulnerability

Please report suspected security issues privately and do not disclose them in public issues or pull requests.

Preferred options:
- Open a GitHub private vulnerability report, if available for this repository.
- Contact the repository owner through a secure channel.

When reporting, include:
- Summary of the issue and affected files or endpoints
- Impact and attack scenario, if known
- Steps to reproduce
- Any proof of concept or suggested remediation

We will review and respond as quickly as possible. Please do not open a public issue for security bugs.
