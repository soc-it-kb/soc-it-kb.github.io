GRC-REG-CLOUD-BASELINE: Cloud Baseline Control Register

Provides the baseline control register structure used to track AWS and Azure implementation status, evidence, gaps, exceptions, ISO mapping and residual risk.

RegisterAWSAzureISO 27001ISO 42001
📋 Reference: GRC-REGISTER-CLOUD-BASELINE
📌 Version: v1.0
👤 Owner: Cyber Security / Cloud Platform Teams
📅 Published: 19 Sep 2026
Live
Purpose
Cloud baseline control register

This register defines the minimum dataset required to track provider-neutral controls, AWS/Azure implementation status, evidence, gaps, treatment, exceptions and residual risk. The downloadable workbook supplied with this pack provides the operational version of the register.

Operational workbook
Downloadable assessment register

Download Cloud Workload Baseline Assessment workbook for assessment tracking, evidence references, gap treatment and exception status.

Register schema
Required fields
FieldDescription
Control IDUnique baseline control identifier such as CLD-WL-IAM-01.
DomainGovernance, identity, logging, network, data protection, compute, vulnerability, backup or inventory.
RequirementProvider-neutral control outcome.
CriticalityMandatory, conditional or recommended.
AWS status / Azure statusImplemented, partially implemented, not implemented, not applicable or exception requested.
Evidence referenceLink to configuration export, dashboard, ticket, IaC module or audit evidence.
Gap typeDesign, implementation, evidence, monitoring, governance or risk acceptance gap.
TreatmentRemediate, compensate, accept, defer or not applicable.
Risk mappingIT risk register identifier where unresolved gap is above appetite.
ISO mappingISO/IEC 27001 and ISO/IEC 42001 applicability.
Workflow
How the register is used
  • Cloud teams complete initial self-assessment against each control.
  • Cyber Security validates evidence and marks reviewer decision.
  • Open gaps are consolidated into the gap register and assigned remediation owners.
  • Exceptions above tolerance are escalated through risk acceptance and GRC reporting.
