Cloud Workload Security Baseline — AWS and Azure

Defines a single cloud workload security baseline for AWS and Azure using common control outcomes, provider-specific implementation guidance, evidence expectations, and ISO-aligned assurance requirements.

AWSAzureISO 27001ISO 42001Evidence-based
📋 Reference: ASM-CLOUD-WORKLOAD-BASELINE
📌 Version: v1.0
👤 Owner: Cyber Security / Cloud Platform Teams
📅 Published: 19 Sep 2026
Live
Purpose
One baseline, two implementation paths

This baseline defines the minimum security outcomes required for AWS and Azure workloads. Cyber Security owns the control outcomes; the AWS and Azure platform teams implement them using native services, infrastructure-as-code, policy-as-code and equivalent compensating controls.

Operating principle. The standard is provider-neutral at the control level. Provider-specific detail appears only as implementation mapping and evidence guidance so the organisation avoids duplicate AWS and Azure policy sets.
Scope
Applies to production and sensitive cloud workloads
  • Production AWS accounts and Azure subscriptions.
  • Internet-facing workloads, APIs, databases, storage, containers, serverless functions and virtual machines.
  • Workloads processing sensitive, regulated, operationally critical or AI-related data.
  • Shared cloud platform services that affect identity, logging, networking, secrets, backup or security monitoring.

Assurance
Evidence and conformance expectations

Each control must be assessed using the Cloud Workload Baseline Assessment Workbook. Acceptable evidence includes exported policy assignments, configuration exports, logging screenshots, SIEM connector evidence, ticket records, access-review exports, IaC modules, backup/restore-test evidence, and approved exception records.

  • Minimum target for mandatory controls: implemented consistently for in-scope workloads.
  • Critical controls must also be monitored and reviewed, not merely configured.
  • Control gaps must result in remediation, compensating control, formal exception or risk acceptance.
